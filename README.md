## 🔍 What we do

| Service | What we test | What you get |
|---|---|---|
| 🌐 **Web Application Security Testing** | Login & sessions, access control, injection, business logic, file uploads, configuration | Manual + tool-assisted testing aligned to **OWASP Top 10 & WSTG** |
| 🔌 **API Security Testing** | REST & GraphQL — authorization (BOLA/BFLA), auth tokens, data exposure, rate limits | Coverage of the **OWASP API Security Top 10 (2023)** |
| 🖥️ **Thick Client Testing** | Windows desktop apps — local storage, traffic, DLL hijacking, memory, hard-coded secrets | Client, network and server-side testing |
| 🧾 **Source Code Review** | Secure code review with manual analysis + SAST | Findings mapped to **CWE** with fix examples |

## 📄 Every engagement includes

- ✅ Clear report with an **executive summary** for management and **technical detail** for developers
- ✅ Each finding rated with **CVSS 3.1**, with proof-of-concept steps and screenshots
- ✅ Step-by-step **fix guidance**
- ✅ **Free retest** to confirm the fixes work
- ✅ Signed NDA and written scope before any testing begins
